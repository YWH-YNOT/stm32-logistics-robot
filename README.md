# STM32F407 物流搬运机器人

2025 年工程训练项目归档。当前仓库保留机器人控制工程压缩包，核心方向是多串口通信、闭环步进电机与舵机执行器控制。

## 项目定位

```text
上位指令 / 传感器
        ↓
UART DMA + Receive-to-Idle
        ↓
FIFO / 命令解析
        ↓
步进电机位置与速度控制 + 270° 舵机状态机
```

## 已实现模块

- STM32F407ZGT6，168 MHz；
- USART1 / 2 / 3 / 6，多串口通信；
- USART DMA 与空闲中断接收；
- 多地址闭环步进电机协议；
- 电机使能、位置、速度、回零与状态读取；
- 270° 舵机离散角度状态机；
- FIFO / 命令接收缓冲。

## 工程说明

源码目前以 `GX_02.zip` 归档，解压后的主要模块包括：

| 模块 | 作用 |
| --- | --- |
| `Emm_V5` | 闭环步进驱动器协议 |
| `motor_control` | 多电机地址、位置/速度与同步控制 |
| `derives_servo` | 舵机角度状态机 |
| `instruct` | 回零触发与结果轮询 |
| `fifo` | 串口数据缓存 |
| `Core/Src/main.c` | 当前联调入口 |

## 复现建议

1. 解压 `GX_02.zip`；
2. 使用 STM32CubeMX 检查 `.ioc` 中的时钟、UART、DMA 与 TIM 配置；
3. 使用 Keil MDK 打开工程并确认 STM32F407 目标器件；
4. 在连接真实执行器前先核对电机地址、方向、脉冲比例、限位和急停；
5. 先分别验证使能、回零、点动和舵机安全角度，再组合完整搬运流程。

## 当前边界

当前归档能够证明通信与执行器控制模块，但主程序仍带有联调阶段痕迹，不能仅凭仓库声称完整物流任务流程已经达到最终验收状态。后续应补充机械结构、接线、完整任务状态机和连续搬运测试数据。
